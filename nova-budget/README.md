# NOVA Budget
Deutschsprachige Budget-App. Start: index.html. Für iPhone-Installation über GitHub Pages bereitstellen, dann in Safari Teilen → Zum Home-Bildschirm.

Enthalten: Einnahmen/Ausgaben mit Datum, Bearbeiten/Löschen, eigene alphabetische Kategorien, Monatsbudgets, Ausgaben-Kreisdiagramm, lokale Insights, CSV-Export, LocalStorage und PWA-Grunddateien.

Hinweis: Browser-LocalStorage ist nicht verschlüsselt und synchronisiert nicht geräteübergreifend. Keine Bankanbindung oder echte KI-Cloud-Funktion. Währungswechsel ändert nur die Anzeige, keine Umrechnung.
